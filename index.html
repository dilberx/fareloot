fareloot

Round-trip flight price monitoring that learns what a route normally costs, then tells you when it crashes.

A fare is only cheap relative to its own history. ₹18,000 to Baku is a steal and ₹18,000 to Colombo is a ripoff, and no fixed threshold can tell those apart. fareloot keeps its own price history per route and flags statistical outliers against that baseline.

How it decides

Per-route baselines, not fixed thresholds

Every price is scored against that specific route's own history using median and median absolute deviation, so one festival-season spike cannot distort the baseline.

A round trip is the unit, not a leg

A cheap outbound paired with a gouging return is not a deal. The return market is checked separately and vetoes anything that looks like a trap.

Door-to-door cost, not just airfare

Departure airports carry the real cost of reaching them, including an overnight train where that applies, so a saving has to survive the journey to collect it.

Built with

Python, SQLite for the price history, and the Travelpayouts Aviasales Data API for fares. It runs as a scheduled job and pushes alerts to Telegram.

Source

Open source at github.com/dilberx/fareloot. Run fareloot poll --provider mock to try the whole pipeline without any API credentials.
